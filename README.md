# LearningDeep
Learning Deep Learning

A repository to hold and document my experiments in deep learning (starting with the _FastAI Deep Learning for Coders_ book), starting with the topic:
* Image Classification

**Why:** Image generation has become a staple in Machine Learning, and with so many resources available, I wanted to get my hands dirty and understand the concepts and mechanics behind it, so I can learn and apply to future projects across other media, like Motion.

**What I tried:** I dove into the book/course and followed along with the exercises in Jupyter notebooks. I realized I would soon forget and lose a lot of the commands I was executing, so I decided to write a mock class and write up some docstrings and calls to methods containing the python I was running, to help me cement my learning.

**Takeaways:** It is inspiring to see how mature image classification has become, and exciting to potentially extrapolate some core concepts to other media such as motion search.


## Contents

The python/learningdeep/examples directory contains a DataLoader class I wrote up to learn about the different methods used in image classification.

There is also an example_utils file containing the actual methods used in my learning exercises. Note that these methods are a record of the actual instructions I executed in a Jupyter notebook, so they are not meant to be sourced/executed as-is.
